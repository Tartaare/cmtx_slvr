Navigation ?

Glissez ou utilisez les flèches pour tourner. Maj + flèches déplace la vue. Molette, pincement ou touches + et − pour zoomer. Début rétablit la vue globale. Recherchez un mot pour le sélectionner au clavier. La vue globale nomme les champs lexicaux. Au zoom, les mots reprennent le premier plan. Les arcs relient des mots proches dans le modèle. La distance affichée est approximative.
